# Білім — жоба контексті

ҰБТ 2027, PISA және ББЖМ (МОДО) дайындығына арналған мобильді-бірінші веб-қосымша. Интерфейс тілі — қазақ тілі.

## Негізгі құжаттар

- `docs/spec.md` — толық спецификация: токендер, компоненттер, экрандар, 3D, қолжетімділік, мазмұн деректері. Барлық шешімдер осыған сүйенеді.
- `design/screens/*.dc.html` — 12 экранның макеті (анықтама ретінде). Өлшемдер, мәтіндер, түстер, күйлер осы файлдарда.
- `design/tokens.css`, `design/tokens.json` — дизайн токендері.
- `prototype/bilim-3d.html` — Three.js 3D сахналарының жұмыс істейтін прототипі.

## .dc.html файлдарын оқу

Бұл файлдар дизайн құралының форматы, оларды тікелей браузерде ашпаңыз.
- Белгілеу `<x-dc>` ішінде, стильдер `style="…"` атрибуттарында.
- `{{атау}}` — төмендегі `renderVals()` ішінен келетін мән.
- `<sc-for list="{{items}}" as="it">` — тізім, `<sc-if value="{{x}}">` — шарт.
- `onClick="{{fn}}"` — оқиға өңдегіш; күй `this.state` / `setState` арқылы.
- `href="Test.dc.html"` — экранаралық навигация (маршрут).
Оларды React компоненттеріне аударыңыз, кодты көшірмеңіз.

## Технология

- React 18 + TypeScript + Vite
- Маршрутизация: React Router
- Стиль: CSS Modules немесе Tailwind; түстер тек `tokens.css` айнымалыларынан
- 3D: Three.js (немесе @react-three/fiber), WebGL жоқ болса SVG fallback
- Күй: алғашында жергілікті күй + mock деректер (`src/mocks`); кейін API

## Ережелер

- Барлық UI мәтіні қазақ тілінде; жолдар `src/i18n/kk.ts` ішінде.
- Басылатын элементтер — нағыз `button` / `a`, биіктігі ≥ 44 px, көрінетін focus.
- Мәтін контрасты ≥ 4.5:1; қосымша мәтін #4B5563.
- `prefers-reduced-motion` кезінде автоматты анимация жоқ.
- Сандар бос орынмен бөлінеді: 2 450.
- Мысал деректер (Саят, 2 450 ұпай, пайыздар) тек mock-та болады.
- ҰБТ құрылымы (пәндер, сұрақ саны, балл, шекті балл) конфигте сақталады, себебі 2027–2029 жылдары формат өзгеруі мүмкін.

## Командалар

Барлығы `bilim/` папкасында іске қосылады:

- `npm run dev` — әзірлеу сервері (Vite)
- `npm run build` — типтерді тексеру (`tsc -b`) және өнім жинағы
- `npm test` — Vitest (jsdom + Testing Library); `npm run test:watch` — бақылау режимі
- `npm run lint` — ESLint (TypeScript, react-hooks, jsx-a11y)
- `npm run format` / `npm run format:check` — Prettier

## Құрылым

- `src/styles/tokens.css` — `design/tokens.css` көшірмесі; токен өзгерсе, екеуін бірге жаңартыңыз.
- `src/styles/global.css` — базалық стиль, focus outline, reduced motion.
- `src/routes.ts` — барлық маршрут; `src/i18n/kk.ts` — UI мәтіні.
- Компонент стильдері — CSS Modules (`*.module.css`).
