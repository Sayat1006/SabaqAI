# Білім — әзірлеуге тапсыру пакеті

## Құрамы

| Жол | Не бар |
| --- | --- |
| `CLAUDE.md` | Claude Code автоматты оқитын жоба контексті мен ережелер |
| `START_PROMPT.md` | Claude Code-қа жіберетін бірінші хабарлама |
| `docs/spec.md` | Толық спецификация |
| `design/tokens.css`, `design/tokens.json` | Дизайн токендері |
| `design/screens/` | 12 экранның макет файлдары (.dc.html) |
| `prototype/bilim-3d.html` | Three.js 3D прототипі — браузерде тікелей ашылады |

## Қалай бастау керек

1. Архивті жаңа жоба папкасына ашыңыз, мысалы `bilim/`.
2. Терминалда осы папкаға кіріп, Claude Code-ты іске қосыңыз: `cd bilim && claude`
3. `START_PROMPT.md` ішіндегі мәтінді көшіріп, жіберіңіз.

## Ескертпелер

- `.dc.html` файлдары дизайн құралының форматы; олар браузерде дұрыс ашылмайды. Экрандардың түрін дизайн полотносынан көріңіз: https://claude.ai/artifact/No8MKtNTAEptLdTBkqsW3y
- Барлық есімдер, ұпайлар мен тест сұрақтары мысал ретінде берілген.
- ҰБТ форматы 2026 жылғы деректерге негізделген; 2027 жылдан жаңа формат пилоттық режимде енгізіледі.
