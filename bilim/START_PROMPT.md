# Claude Code-қа бірінші хабарлама

Төмендегі мәтінді көшіріп, Claude Code-қа жіберіңіз. Оны бір қадамнан ғана бастаңыз: әр кезең біткенде тексеріп, келесісін сұраңыз.

---

Бұл папкада «Білім» оқу қосымшасының дизайны мен спецификациясы бар. Алдымен `CLAUDE.md` және `docs/spec.md` файлдарын оқы, содан кейін `design/screens/` ішіндегі экрандарды қара.

Мақсат: React 18 + TypeScript + Vite негізінде қосымшаның бірінші нұсқасын құру. Жұмысты кезеңмен жаса, әр кезеңнен кейін тоқтап, не істегеніңді айт:

1. **Жоба негізі.** Vite + React + TS жобасын құр, React Router қос, `design/tokens.css`-ті жаһандық стиль ретінде қос, Onest қарпін жүкте. ESLint, Prettier, Vitest баптап, `CLAUDE.md`-ге командаларды жаз.
2. **Негізгі компоненттер.** Спецификациядағы «Компоненттер мен күйлер» кестесі бойынша: Button, IconButton, Pill, AnswerOption, SegmentedTabs, ProgressBar, SegmentedProgress, ProgressRing, ModeCard, BottomNav. Әрқайсысына барлық күйлерді және қолжетімділік атрибуттарын қос.
3. **Mock деректер.** `src/mocks` ішінде пайдаланушы, прогресс, ҰБТ конфигі (пәндер, сұрақ саны, балл, шекті балл) және әр режимге 3–5 үлгі сұрақ. Барлық мәтін `src/i18n/kk.ts`-те.
4. **Басты бет** (мобильді + десктоп, spec-тегі брейкпоинттер).
5. **ҰБТ ағыны:** пәндер → тест (күйлер машинасы, таймер, белгілеу, пернетақта) → нәтиже → қателерді талдау. Тест логикасына юнит-тесттер жаз.
6. **Қалған экрандар:** PISA, ББЖМ, профиль/рейтинг, онбординг, шеткі күйлер.
7. **3D:** `prototype/bilim-3d.html` негізінде үш сахнаны React компоненті ретінде қос (lazy load, IntersectionObserver, SVG fallback, reduced motion).

1-кезеңнен баста.
