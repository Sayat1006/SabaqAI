# AI Nur

Мұғалімге арналған AI көмекші: ҚМЖ, презентация, сабақ суреттері, саралау деңгейлері бар тест және оқушыларға кері байланыс.

Толығымен **тегін** инфрақұрылымда жұмыс істейді:

| Бөлік | Қызмет |
|---|---|
| Сайт | **Vercel** (тегін Hobby тарифі) — React + Vite статикалық сайты |
| Кіру жүйесі, дерекқор, сервер функциялары | **Supabase** (тегін тариф) — Auth, Postgres + RLS, Edge Functions |
| Жасанды интеллект | **Google Gemini API** (тегін тариф) — кілт тек Supabase Edge Function ішінде сақталады |

## Құрылымы

- **Кіру беті** — «Мұғалім» және «Әкімші» қойындылары
- **Басты бет** — бүйір мәзір, сәлемдесу, іздеу, хабарландырулар, статистика, жылдам жасау, соңғы жобалар
- **ҚМЖ жоспарлау** — ресми үлгідегі қысқа мерзімді жоспар (Word/PDF), одан презентация жасауға болады
- **Презентация** — тақырып бойынша слайдтар: 3D карусель, толық экран, PPTX
- **Сурет генерациясы** — сабақ иллюстрациялары (SVG/PNG)
- **Тапсырмалар** — деңгейлік тест, PISA, ҰБТ, БЖБ/ТЖБ, шығармашылық тапсырмалар; оқушыларға сілтемемен жіберу және **тірі викторина** (оқушылар телефоннан 6 таңбалы кодпен қосылып, уақытқа жарысады; көшбасшылар кестесі)
- **Сабақ кестесі** — апталық кесте (күн, уақыт, пән, сынып); әр сабақтың тақырыбы КТЖ-дан алынады, басты бетте «Бүгінгі сабақтар» және бір батырмамен ҚМЖ
- **КТЖ** — тоқсандық/жылдық күнтізбелік-тақырыптық жоспар: бөлімдер, тақырыптар, оқу мақсаттары, БЖБ/ТЖБ, күндері автоматты; өңдеу, Word (альбомдық), әр сабақтан ҚМЖ жасау
- **Оқушы прогресі** — барлық тест нәтижелері сынып кестесінде (оқушы × тест), әр оқушының графигі, A/B/C деңгейлері, қайталау керек тақырыптар, AI тоқсандық қорытындысы, Excel
- **Құжаттар** — оқушыға мінездеме, ата-ана жиналысының баяндамасы, тәрбие сағаты мен іс-шара сценарийі, тоқсандық есеп; өңдеу және ресми рәсімдегі Word
- **Интерфейс тілі және режим** — сайт қазақша, орысша және ағылшынша; күндізгі / түнгі / жүйелік режим (профиль мәзірінде және кіру бетінде). Таңдау құрылғыда сақталады
- **Материал тілі: қазақша, орысша, ағылшынша** — ҚМЖ, КТЖ, презентация, тапсырмалар мен құжаттар таңдалған тілде жасалады (Word/PPTX белгілері, оқушы беті және тірі викторина да сол тілде)
- **Менің жобаларым** — барлық материалдар, сүзу және іздеу
- **Сабақ құралдары** — таймер, кездейсоқ оқушы, топқа бөлу, бағдаршам, шу өлшегіш (микрофон тек құрылғыда өңделеді), рефлексия әдістері; бәрі толық экранда
- **Телефонға орнату (PWA)** — Android/Chrome-да «Орнату» батырмасы, iPhone-да Safari → «Бөлісу» → «Басты экранға қосу»; интернет жоқ кезде ескерту беті шығады
- **Жеке бет** — аватар, аты-жөні, пән, мектеп, сабақ беретін сыныптар, біліктілік санаты, өтіл, телефон, құпия сөзді өзгерту
- **Әкімші панелі** — аккаунт ашу/өшіру/жою, құпия сөзді ысыру, рөл, әрекеттер журналы, Excel экспорты

Мұғалімдер өз бетінше тіркеле алмайды — аккаунтты тек әкімші ашады. Кіру бетінде «Мұғалім» және «Әкімші» қойындылары бар.

Мұғалімнің жобалары (ҚМЖ, презентациялар, суреттер, тесттер) Supabase дерекқорында сақталады, сондықтан кез келген құрылғыдан көрінеді. Бұрын браузерде сақталған жобалар бірінші кіргенде автоматты түрде дерекқорға көшіріледі.

## Тегін орнату

### 1. Supabase
[supabase/README.md](supabase/README.md) нұсқаулығы бойынша: жоба құру → `schema.sql`, `update-2-projects-profile.sql` `update-3-editing-sharing.sql`, `update-4-feedback.sql`, `update-5-task-types.sql`, `update-6-telegram.sql`, `update-7-docs-live.sql`, `update-8-ktzh.sql`, `update-9-english.sql` және `update-10-schedule.sql` орындау → бірінші әкімші → `admin-actions` және `ai-generate` функцияларын жариялау → `GEMINI_API_KEY` секретін қою ([aistudio.google.com/apikey](https://aistudio.google.com/apikey) сайтынан тегін алынады).

### 2. Vercel
1. [vercel.com](https://vercel.com) → GitHub арқылы кіру → **Add New → Project** → осы репозиторийді таңдау.
2. **Environment Variables** бөліміне қосыңыз:
   - `VITE_SUPABASE_URL` — Supabase → Project Settings → API → Project URL
   - `VITE_SUPABASE_ANON_KEY` — сол жердегі `anon` / `public` кілті
3. **Deploy** басыңыз. Сайт `https://<жоба-аты>.vercel.app` мекенжайында ашылады. Кейінгі әр `git push` автоматты түрде жаңартады.

`service_role` кілтін ешқашан Vercel-ге немесе `.env`-ке қоймаңыз — ол тек Supabase ішінде қалады.

### Тегін тарифтердің шектеулері
- Supabase-тің тегін жобасы бір апта қолданылмаса, «ұйықтап» қалады — Dashboard-тан бір батырмамен қайта қосылады.
- Gemini-дің тегін тарифінде сұраныс саны шектеулі, ал Google сұраныстарды модельдерін жақсартуға пайдалануы мүмкін. Оған тек сабақ мазмұны (тақырып, пән) жіберіледі.

## Жергілікті іске қосу

```bash
npm install
cp .env.example .env   # Supabase URL мен anon кілтін қойыңыз
npm run dev
```

```bash
npm run build   # өндірістік жинақ
npm run lint
```

Стек: React 19 + TypeScript + Vite + Tailwind CSS 4 + React Router + Supabase.
