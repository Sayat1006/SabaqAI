# Sabaq AI

Мұғалімге арналған AI студия. Сыртқы түрі мен басты беті — Sabaq AI дизайны, ал ішкі бөлігі (аутентификация, дерекқор, AI генерациясы, құралдар) — S-AI платформасынан алынған.

Толығымен **тегін** инфрақұрылымда жұмыс істейді:

| Бөлік | Қызмет |
|---|---|
| Сайт | **Vercel** (тегін Hobby тарифі) — React + Vite статикалық сайты |
| Кіру жүйесі, дерекқор, сервер функциялары | **Supabase** (тегін тариф) — Auth, Postgres + RLS, Edge Functions |
| Жасанды интеллект | **Google Gemini API** (тегін тариф) — кілт тек Supabase Edge Function ішінде сақталады |

## Құралдар

- **Сабақ жоспарлау:** ҚМЖ (Word/PDF экспорты), КТЖ (Word/Excel/PDF), сабақ кестесі
- **AI студия:** тақырып бойынша презентация (3D карусель, толық экран, PPTX), сурет генерациясы (SVG/PNG), Sabaq көмекшісі, материал бойынша сұрақтар, ЖИ диктант
- **Интерактивті:** Дода (викторина, PPTX), виртуалды зертхана, код компиляторы
- **Кітапхана және бағалау:** ҮОБ энциклопедиясы, материалдар кітапханасы, сыныптар мен тесттер
- **Әкімші панелі:** аккаунт ашу/өшіру/жою, құпия сөзді ысыру, рөл, әрекеттер журналы, Excel экспорты

Мұғалімдер өз бетінше тіркеле алмайды — аккаунтты тек әкімші ашады. Кіру бетінде «Мұғалім» және «Әкімші» қойындылары бар.

Мұғалімнің жобалары (ҚМЖ тарихы, презентациялар, суреттер, сыныптар, кесте) әзірге браузерде (localStorage) сақталады.

## Тегін орнату

### 1. Supabase
[supabase/README.md](supabase/README.md) нұсқаулығы бойынша: жоба құру → `schema.sql` орындау → бірінші әкімші → `admin-actions` және `ai-generate` функцияларын жариялау → `GEMINI_API_KEY` секретін қою ([aistudio.google.com/apikey](https://aistudio.google.com/apikey) сайтынан тегін алынады).

### 2. Vercel
1. [vercel.com](https://vercel.com) → GitHub арқылы кіру → **Add New → Project** → осы репозиторийді таңдау.
2. **Environment Variables** бөліміне қосыңыз:
   - `VITE_SUPABASE_URL` — Supabase → Project Settings → API → Project URL
   - `VITE_SUPABASE_ANON_KEY` — сол жердегі `anon` / `public` кілті
3. **Deploy** басыңыз. Сайт `https://<жоба-аты>.vercel.app` мекенжайында ашылады. Кейінгі әр `git push` автоматты түрде жаңартады.

`service_role` кілтін ешқашан Vercel-ге немесе `.env`-ке қоймаңыз — ол тек Supabase ішінде қалады.

### Тегін тарифтердің шектеулері
- Supabase-тің тегін жобасы бір апта қолданылмаса, «ұйықтап» қалады — Dashboard-тан бір батырмамен қайта қосылады.
- Gemini-дің тегін тарифінде сұраныс саны шектеулі, ал Google сұраныстарды модельдерін жақсартуға пайдалануы мүмкін. Оған тек сабақ мазмұны (тақырып, пән) жіберіледі.

## Жергілікті іске қосу

```bash
npm install
cp .env.example .env   # Supabase URL мен anon кілтін қойыңыз
npm run dev
```

```bash
npm run build   # өндірістік жинақ
npm run lint
```

Стек: React 19 + TypeScript + Vite + Tailwind CSS 4 + React Router + Supabase.
