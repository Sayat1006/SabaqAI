# Sabaq AI

Мұғалімге арналған AI студия: **ҚМЖ** (қысқа мерзімді жоспар), **презентация** және **сабақ суреттерін** бірнеше минутта дайындайды. Дизайн — [Sabaq AI макеті](https://claude.ai/artifact/2FYr6dcFffgusgfLUSHrLQ) бойынша.

## Мүмкіндіктер

| Бөлім | Не істейді |
|---|---|
| Кіру | Мұғалім / Әкімші қойындысы, «Есте сақтау», алғаш кіргенде уақытша құпия сөзді ауыстыру міндетті |
| Басты бет | Жеке статистика, соңғы жобалар, іздеу, хабарландырулар |
| ҚМЖ | Пән, сынып, тоқсан, тақырып, оқу мақсаты, құндылық → ресми үлгідегі толық жоспар; **Word (.docx)** және **PDF** (басып шығару) |
| Презентация | Тақырып, стиль (4 түрі), слайд саны → 3D карусель, толық экранда көрсету, **PowerPoint (.pptx)** |
| Сурет | Сипаттама + стиль (акварель, жалпақ, реалистік, сызықтық, изометрия) → векторлық SVG иллюстрация; **SVG / PNG** жүктеу |
| Жобалар | Барлық материалдар сақталады, сүзу, іздеу, жою |
| Әкімші панелі | Аккаунт ашу (уақытша құпия сөз), бұғаттау/белсендіру, құпия сөзді жаңарту, жою, статистика |

Мазмұнды Claude (Anthropic API) құрылымдық JSON түрінде генерациялайды. `ANTHROPIC_API_KEY` орнатылмаса, жүйе **демо режимде** үлгі мазмұнмен толық жұмыс істейді.

## Іске қосу

Node.js ≥ 22.13 қажет (дерекқор — кірістірілген `node:sqlite`).

```bash
npm install
cp .env.example .env        # кілтті және әкімші деректерін толтырыңыз
export $(grep -v '^#' .env | xargs)
npm start                   # http://localhost:3000
```

Алғаш іске қосқанда әкімші жасалады (әдепкі: `admin@sabaq.ai` / `admin12345` — бірінші кіргенде құпия сөзді ауыстыру сұралады). Әкімші панелінде мұғалімдерге аккаунт ашып, берілген уақытша құпия сөзді жіберіңіз.

Docker:

```bash
docker build -t sabaq-ai .
docker run -p 3000:3000 -v sabaq-data:/app/data -e ANTHROPIC_API_KEY=... -e ADMIN_PASSWORD=... sabaq-ai
```

Өндірісте HTTPS артында `COOKIE_SECURE=1`, reverse proxy болса `TRUST_PROXY=1` қойыңыз.

## Тесттер

```bash
npm test
```

Тесттер Anthropic API-дың жергілікті жалған серверін қолданып, кіру, әкімші әрекеттері, ҚМЖ/презентация/сурет генерациясы, Word/PowerPoint экспорты, SVG тазалау және қолжетімділік шектеулерін тексереді.

## Құрылымы

```
server/
  index.js    Express: API, беттер, сессиялар
  db.js       SQLite кестелері (users, sessions, projects, notifications)
  auth.js     scrypt хэштеу, сессия токендері, кіру әрекеттерін шектеу
  ai.js       Claude сұраулары (Zod схемалары) + демо генераторлар
  export.js   ҚМЖ → .docx, презентация → .pptx
  svg.js      Генерацияланған SVG-ді тазалау
  catalog.js  Пәндер, құндылықтар, стильдер
public/
  pages/      login, dashboard, qmz, presentation, images, projects, admin
  js/, css/   Әр беттің скрипті мен стилі
```
